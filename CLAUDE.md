# Talking Scores

Django application that converts music scores into spoken-word descriptions.
Run tests with `python manage.py test` from the repository root.

# Compact instructions

Carry the following across any compaction; drop anything else first:

- Current branch name.
- Path to the current handoff file.
- Phase identifier of the work in progress.
- Acceptance checks not yet passing, each with its exact command.
- Decisions already taken, each with the reason it was taken.
- Paths of every file modified so far.

Restate these verbatim rather than summarising them. A decision without its
reason will be re-litigated; a check without its command cannot be re-run.
