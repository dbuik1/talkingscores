Talking Scores

Change Log

This site is an independently maintained fork of the original Talking Scores project, created by Ben Timms. This fork is developed and maintained by David Buik and is hosted at talkingscores.davidbuik.com.

This page details the changes made specifically within this fork. The dates represent the approximate date when particular changes were committed in Git - the actual date that a change became live on this site may differ slightly. For the full, unabridged commit history, see the source repository on Github.

Current State

  • This project currently may produce an acceptable output for fairly simple scores - potentially with multiple instruments.
  • At present - most of the testing is carried out using musicxml files exported from MuseScore.
  • If the musicxml file is too large - then processing will time out (after about 5 minutes)...

3rd April 2026

  • Fixed a number of security vulnerabilities, bugs, and code quality issues, including: removing a hardcoded secret key, fixing the SMTP email configuration, correcting around 60 broken CSS variable names, adding input validation, fixing a file descriptor leak, restricting CORS, hardening protection against path traversal attacks, pinning dependency versions, and adding upload size limits.

21st March 2026

  • Deployed the site to Railway hosting, including several fixes to get the Python build working correctly (pinning the Python version and adjusting the build configuration).
  • Fixed a crash by making sure the media directory exists before writing to the log file.
  • Improved security by restricting trusted hosts and origins to those explicitly allowed.
  • Fixed the CSS stylesheet not loading correctly after deployment.
  • Added dark mode support that follows your operating system's preference, and fixed dark mode styling on the talking score output pages.

25th July 2025

  • Fixed the pickup bar not being described at all, and changed some output styles in talkingscore.html.
  • Refactored the templates to use British English throughout, and removed the "beta" tag from the heading to match the current live version.
  • Improved the appearance of the site and the outputted HTML, and made the key signature description more user-friendly.

24th July 2025

  • Carried out a major clean-up of talkingscoreslib.py for maintainability.
  • Added proper Django app configuration, with docstrings and more modern settings.
  • Fixed a path traversal security vulnerability in file handling.
  • Added an essential test suite covering core functionality and security.
  • Fixed a missing space after a comma in the template output.
  • Carried out a major reorganisation of the CSS and improved accessibility.
  • Improved the structure and maintainability of views.py.
  • Improved the structure and consistency of the templates.

23rd July 2025

  • Refactored talkingscoreslib.py and talkingscore.html to clean up the code.

18th July 2025

  • Fixed a scrolling bug and improved interactivity on the score page.
  • Fixed the "Octave Announcement" dropdown on the options page so that it correctly collapses when its parent option is set to "None".
  • Overhauled the options page with a live-updating preview panel; fixed font size, spacing and dark mode contrast issues; fixed a critical bug causing incorrect bar segmentation; corrected the logic for presets, colouring and conditional form fields; and improved overall accessibility and stability.

17th July 2025

  • Standardised how musical events are rendered, fixing a number of formatting bugs.
  • Simplified the display for scores with only a single instrument.
  • Made the options form controls stateful and dynamic.
  • Added a floating navigation ribbon to the score page.
  • Enhanced the options page and added further accessibility features.

16th July 2025

  • Replaced the deprecated music21 .flat property with .flatten().
  • Added custom description options and fixed several score rendering bugs.

15th July 2025

  • Sped up page loads by caching generated MIDI files using a flag-file system, so cached scores no longer regenerate MIDI unnecessarily.
  • Switched to generating the HTML output dynamically on every request, rather than caching it, so that user-selected options are always applied correctly - while MIDI generation remains cached for speed.
  • Added inline dynamics and key signature description options.

14th July 2025

  • Fixed grace notes being skipped instead of being described correctly.
  • Improved the accuracy and conciseness of the homepage: added a drag-and-drop option to the instructions, restored the link back to Figurenotes, and removed italics from the "No file selected" text.

13th July 2025

  • Completed the colour customisation options and reorganised the options form for clarity.
  • Added an option to omit repetition information from the description.
  • Fixed MIDI file handling, and ensured all files are fully prepared before the talking score is displayed.
  • Fixed the backend for the extra colour options and repetition settings, added a basic repetition option, and added more examples and explanations to the options form.

11th July 2025

  • Added drag-and-drop file upload, a button to delete an uploaded file, and improved dark mode compatibility.
  • Added more robust UTF-8 encoding, and began work on more complete colour customisation options.

10th July 2025

  • Added a dark mode switch.
  • Improved the focus indicator and other styling across the site.

9th July 2025

Fork created, based on the original Talking Scores project by Ben Timms.
